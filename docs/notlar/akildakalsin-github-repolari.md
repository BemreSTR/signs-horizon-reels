# Akılda kalsın: animasyon kalitesini artıran GitHub repoları

Kullanıcı notu (X gönderisi özeti). İlham ve stil keşfi içindir; kodu doğrulamadan depoya alma, içerik kuralları ([docs/04](../04-icerik-dogrulugu.md), [docs/08](../08-gorsel-dil.md)) her zaman önce gelir.

1. `yihui-dev/awesome-opus5-5-videos` — Claude Opus 5.5 ile üretilmiş animasyon arşivi; arkasındaki promptlar incelenebilir.
2. `lemomo-ai/lemo-opuscar` — Claude Code için 66 video/animasyon stili; AI video modeli gerekmeden kodla üretilen örnekler (listedeki en kullanışlılardan biri).
3. `mexicat/pdoom-video` — tamamen kodla yapılmış müzik videosu: müzik senkronu, karaoke efektleri, 3B görseller, 4K render.
4. `JohnHeibel/PDoomVideo` — aynı şarkı için başka bir müzik videosu; iki yaklaşımı karşılaştırmak için.
5. `Vincentwei1021/mg-styles-15` — 15 motion graphics stili (10 sn örnek, prompt ve kaynak kod).
6. `JohnHeibel/ClaudeAnimationBase` — çizgi film tarzı karakter animasyonu başlangıç projesi (31 duygu ifadesi). *Kanalda insan/karakter tasviri kuralları nedeniyle doğrudan kullanılmaz.*
7. `athemeroy/awesome-claude-5-5-videos` — Claude ile üretilmiş animasyonların ve iş akışlarının derlemesi.
8. `joeseesun/opus-video-prompts` — 54 örnek video üretim promptu (motion graphics, kodla video).

Örnek proje: "Aura — Hear the Light" (LemoLab, Lemo-Opuscar). İlk iki repo yeni stil keşfi için başlangıç noktası.
